# Design: 多语言

## 语言

| 代码 | 用途 |
| --- | --- |
| `zh-CN` | 默认，现有文案 |
| `zh-Hant` | 港式繁体（`zh-HK` 用字：茅台保留「台」） |
| `en` | 界面 + 研究词表 |

不把 `上游/中游/下游` 的「游」转成「遊」。

## 两层翻译

1. **界面键**：导航、表头、按钮，放在看板 `messages`。
2. **研究字符串**：Python 词表（因子名、备注、策略句）。快照 JSON 带上 `i18n`，看板与 CLI 共用算法：精确匹配 → 片段替换 → 英文名替换 → 繁体单字转换。

打分仍输出中文键名；展示层翻译。前端不重算分数。

## 语言选择

- Cookie `locale`。
- 无 cookie 时读 `Accept-Language`（`zh-HK`/`zh-TW` → 繁体，`en*` → 英文，其他 → 简体）。
- CLI：`--lang zh-CN|zh-Hant|en`。

## 非投资建议

每种语言都有对应免责声明，禁止省略。
