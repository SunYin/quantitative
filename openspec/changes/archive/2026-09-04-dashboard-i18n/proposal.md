# Change: 看板与 CLI 多语言

覆盖 A 股 / 港股 / 美股用户的界面语言，不改打分公式。

## Why

研究宇宙跨三地，界面却只有简体中文。港股用户需要繁体，海外用户需要英文；行业名、个股名和 AI 产业链说明也应跟着切换。

## What Changes

- 看板提供 **简体（zh-CN）/ 繁体（zh-Hant）/ 英文（en）**，顶栏可切换，写入 cookie，并尊重 `Accept-Language`。
- 个股、行业、产业链展示名：英文用已有 `name_en`，繁体用港式用字转换。
- 研究文案（因子名、备注、策略、免责声明）经词表翻译；分数仍来自 Python 引擎。
- CLI 增加 `--lang`，例如 `python -m quant --lang en industry AI`。
- 所有语言的免责声明仍须写明：不构成投资建议。

## Non-goals

- 不把估值公式搬到 TypeScript。
- 不自动翻译用户粘贴的任意研报正文。
- 不按语言拆三份快照文件。
- 不把文档站 `docs/` 做成完整三语（仅看板与 CLI 输出）。

## Impact

- 市场：A / HK / US / 港股通 的展示语言，不影响名单与额度规则本身。
- 样本与实时数据在任何语言下都不是投资建议。
