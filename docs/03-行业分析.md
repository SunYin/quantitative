# 行业分析怎么做

行业分析的目标不是写“前景广阔”，而是判断：**利润会留在哪一层、留给谁、能留多久**。

## 一张标准作业纸

1. **产业链地图**：上游资源/设备 → 中游制造 → 下游品牌/渠道。标出价格谈判权。
2. **需求**：量（渗透、更新、出口）和价（ASP、折扣、汇率）。分开看。
3. **供给**：产能周期、退出壁垒、国产替代或海外设厂。
4. **竞争结构**：CR5、HHI、是否在份额集中。分散且同质化的行业很难有超额收益。
5. **利润池趋势**：收入增长但价格战，利润池可能在缩小。
6. **政策**：准入、补贴、反垄断、出口管制、医保/利率。
7. **估值周期**：当前倍数处于五年/十年分位的哪里。
8. **颠覆**：技术路线、渠道迁移、监管一次切断商业模式。

本仓库的行业分把以上压成 0–100 分，权重见 `quant.industry`。

## 跨市场行业怎么比

| 行业 | 主市场 | 关键变量 | 常用估值 |
| --- | --- | --- | --- |
| 白酒 | 纯 A 股 | 宴席/礼品、渠道库存、批价 | PE、现金流 |
| 动力电池 | A + 港股 | 装车量、碳酸锂、海外份额 | EV/EBITDA、PE |
| 新能源车 | A + 港股 | 价格战、出口、单车利润 | PE、销量 |
| 中资银行 | A + H | 净息差、不良、地产敞口 | PB-ROE、股息 |
| 美股银行 | 美股 | 美债利率、资本回报 | PB |
| 互联网平台 | 港股 / 美国 | DAU、广告、监管、竞争补贴 | P/S、FCF、EV/EBITDA |
| 本地生活 | 港股 | 补贴、订单密度 | EV/EBITDA |
| 半导体 / 晶圆代工 | 美股主定价 | 资本开支、库存、出口管制 | PE、EV/Sales |
| 云计算 | 美股 / 港股 | 租用 GPU 的差价与折旧 | PE、FCF |
| 消费电子 | 美股 | ASP、回购、端侧 AI | PE、FCF |

## 产业链（例如 AI 上下游）

`python -m quant industry AI` 或看板输入「AI / 人工智能 / 算力」会展开：

1. **上游** 全球半导体、晶圆代工：算力与先进制程，利润最厚，也是瓶颈。
2. **中游** 云计算、互联网平台：把算力转租或做成应用分发。
3. **下游** 消费电子、本地生活：入口和应用。AI 常常是费用或 ASP 叙事，不是和 GPU 同一利润池。

链条是研究地图，不是完整产业普查，更不是投资建议。

比较 CATL A/H 与英伟达，不是比 PE 数字，而是比：谁拥有不可替代的需求、谁的资本开支会反噬利润、谁的客户会自制。

## 周期位置

- **trough**：估值低、叙事差，先看供给是否出清。
- **early**：需求拐点被数据证实，但一致预期还没完全上修。
- **mid**：景气公认，拼谁有份额和成本。
- **late**：资本开支高峰、新进入者、一致目标价上修过快。

白酒这类品牌行业周期弱，更应看批价和库存而不是产能。电池和半导体周期强，先画产能。

## 行业轮动在组合里的用法

1. 行业分 ≥ 70：在行业内做质量-价值精选。
2. 行业分 55–70：标配，避免把单一个股当成行业 beta。
3. 行业分 < 55：只有深度折价的质量龙头才值得跟，否则等待。

政策分对 A 股、港股中资股权重要高于美股。美股行业轮动更多看利率和盈利修订。
