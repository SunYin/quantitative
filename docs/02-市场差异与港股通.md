# A 股、港股、美股与港股通

三地不是“同一个股票换个代码”，而是三套定价体系。

## 港股通 / 沪深股通

- **南向港股通**：内地投资者经沪/深港通买符合名单的港股。
- **北向沪深股通**：海外及香港投资者买符合名单的 A 股。
- 不是全市场开放，是**名单 + 额度 + 闭环换汇**。
- 标的进出入名单、停牌、风险警示，都会突然改变可投资集合。

研究含义：

1. 南向高度集中在少数龙头（互联网、银行、保险、部分消费）。排名变化比单日净买入更有用。
2. 港股通能缩小 A/H 价差，但不能消灭：不同股份、不同税、不同借券、不同投资者约束。
3. 额度打满的交易日，价格信号失真，应记为微观结构事件。
4. 非港股通港股，定价更接近海外资金，内地叙事传导慢。

## A/H 溢价怎么用

```
溢价 ≈ (A股价 × 人民币兑港币) / H股价 − 1
```

常见解释，而不是交易指令：

- A 股贵：内地资金偏好、回购/纳入指数、卖空困难
- H 股便宜：治理折价、海外风险溢价、做空便利
- 价差收窄：南向大买、两地流动性接近、事件驱动（重组/私有化）

不要把价差当成“必然回归”。很多银行股溢价可以维持十年。

## 美股对照为什么必要

同一行业在美股往往有更长的披露和更干净的股东回报数据（回购、SBC、分部）。
做中概或 A 股成长股时，用美股同行校准：

- 软件/平台：规则 40、SBC 后 FCF
- 银行：ROTE、净息差、信贷成本
- 半导体：库存天数、客户资本开支、毛利率

## 治理红旗（按市场）

**A 股**：大股东质押、资金占用、商誉+应收暴增、审计变更、问询函回避。

**港股**：反复供股折价融资、长期不派息的现金牛、壳价值、审计延迟、关联收购。

**美股**：激进非 GAAP、关键人风险、持续亏损却高 SBC、going-concern、关联融资。
