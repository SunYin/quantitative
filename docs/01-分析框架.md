# 跨市场股票分析框架

本框架把研究拆成四层，避免一上来就看目标价或消息面。

```
宏观与流动性 → 行业利润池 → 公司质量与治理 → 估值与交易结构
```

三地市场用**同一套质量语言**，用**不同的估值与交易语言**。

## 1. 自上而下

先回答三个问题：

1. 钱松还是钱紧？（利率、信用、汇率、财政）
2. 这个行业未来两年利润池是扩还是缩？
3. 当前估值分位是否已经透支了景气？

A 股对政策和流动性更敏感；港股对美元流动性和南向资金更敏感；美股对美债实际利率和盈利修订更敏感。

## 2. 自下而上

对公司只打五类分：

| 维度 | 看什么 | 常见翻车点 |
| --- | --- | --- |
| 盈利能力 | ROE、ROIC、净利率 | 用一次性收益抬 ROE |
| 现金流 | OCF/NI、FCF | 资本开支周期被当成自由现金流 |
| 资产负债表 | 净负债/EBITDA、银行看 NPL/CET1 | 表外和永续债 |
| 稳定性 | 三年增长与盈利波动 | 把周期高点 CAGR 外推 |
| 治理 | 关联交易、应收、同股不同权、稀释 | 港股老千、A 股资金占用、美股 SBC |

质量合格后，才进入估值。质量不合格，便宜也可以更便宜。

## 3. 估值：先选尺子

- 消费龙头、稳定赚钱：PE / PEG / 业主盈余
- 银行保险：PB-ROE、P/EV、股息贴现
- 互联网：P/S（仍亏损或利润波动大）+ FCF yield（已规模化）
- 周期与制造：中周期 EV/EBITDA，不用高峰 PE
- 高增长科技：情景 DCF，必须做资本开支和份额敏感性

跨市场比较时，先统一货币和股份类别，再比倍数。茅台的 A 股 PE 不能直接当腾讯或苹果的锚。

## 4. 交易结构

研究结论要翻译成**仓位、持有期、证伪条件**：

- 建议研究仓位上限随质量、估值、市值、beta 收缩
- 港股通/北向资金是拥挤度，不是基本面
- A/H 溢价是投资者结构，不是无风险套利

## 5. 每周工作流

1. 更新利率、汇率、南向/北向持仓变化。
2. 行业记分卡：增长、集中度、政策、估值分位是否变化。
3. 组合内公司：只跟踪关键假设，不重读全文研报。
4. 新研报：先复述逻辑，再看目标价。
5. 记录证伪条件。触发就降仓或退出研究，不找补逻辑。

## 6. 本仓库如何落地

```bash
python -m quant universe
python -m quant analyze 00700.HK
python -m quant industry 互联网平台
python -m quant research cmb-ah
python -m quant demo
```

样本宇宙用于演示方法。接入实时财务与行情后，把 `sample_data.py` 换成数据适配层即可，打分函数不用重写。
