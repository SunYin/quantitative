# 策略手册

仓库内置四条可计算的研究策略。它们输出的是**研究优先级**，不是下单指令。

## 1. 质量-价值（三地通用）

**公式**：`0.45 × 质量 + 0.40 × 估值 + 0.15 × 技术代理`

规则：

- 质量 ≥ 70 且估值 ≥ 60 → 重点研究
- 质量 ≥ 60 且估值 ≥ 50 → 观察名单
- 质量 < 45 → 先排除，不管多便宜

市场修正已经写进估值模块：A 股默认更贵，港股通标的有轻微流动性加分，美股强调 FCF。

## 2. A/H 溢价

对同时存在 A 股与 H 股的样本，用研究汇率计算溢价。

用法：

- 溢价高 + 质量合格 → 把 H 股作为同一公司的更便宜研究入口
- 溢价极低 → 检查是否拥挤，而不是追涨 A 股
- 永远不要假设可以同时买卖并锁定无风险利润

## 3. 行业轮动

对白酒、动力电池、中资银行、互联网平台、全球半导体打分。

先行业、后个股。避免“先爱上公司再论证行业”。

## 4. 互联互通资金

南向/北向 20 日持股变化是**拥挤度**。与质量、估值同向才进入跟踪；单独的资金脉冲忽略。

## 组合约束（研究用）

`position_cap()` 给出单票研究仓位上限：

- 质量高且不贵：最高约 12%
- 质量或估值弱：约 4%
- 高 beta、小市值再打折
- 硬顶 15%

这是为了强迫分散，不是建议你按此买入。

## 以后如何接实盘数据

1. 用行情/财务 API 填充 `Stock` 与 `Financials`。
2. 用申万或 GICS 成分替换 `INDUSTRIES`。
3. 用交易所港股通持股文件替换 `CONNECT_FLOWS`。
4. 把卖方 PDF/晨会纪要转成 `ResearchReport.body` 再打分。

打分与策略层保持纯函数，便于回测和单元测试。
