# 如何读行业分析与卖方研报

研报是**假设生成器**，不是决策外包。卖方的激励是佣金、排名和投行关系，不是你的净值。

## 十分钟读法

1. 封面评级先不看，先读核心结论，用两句话复述。
2. 找出 1–2 个可证伪假设：量、价、费率、市占、净息差、税率。
3. 把目标价还原成隐含倍数，对比十年分位和同行。
4. 风险章节：是真实情景，还是“宏观经济波动”模板。
5. 利益冲突：是否承销、做市、首次覆盖即买入。

## 好报告的特征

- 有明确的“若 X 不成立则逻辑垮”
- 有一手证据：渠道、排产、10-K、交易所公告，而不是复述管理层
- 估值方法匹配行业，并做敏感性
- 对 A/H 或 ADR 价差有解释
- 下行情景给出价格，而不是只给上行

## 差报告的特征

- “空间巨大且确定”“必涨”
- 首次覆盖 + 高目标价 + 承销关系
- 只有 PE 扩张故事，没有利润来源
- 风险只有宏观模板
- 把北向/南向资金当成基本面证据

`quant research` 会对样本研报打分，并抽出逻辑句、数字和红旗。启发式不是 NLP 研报引擎，但足够训练阅读纪律。

## 按市场补作业

**A 股研报**：核对交易所公告、问询函、大股东质押、北向名单。政策段落要单独验证，不轻信“催化不断”。

**港股/港股通研报**：核对 HKEX 通函、南向持股、WVR、关连交易。注意英文报告与中文营销稿口径是否一致。

**美股研报**：优先 10-K Item 1A、电话会 Q&A、13F 与回购。非 GAAP 要还原 SBC 和资本开支。

## 行业深度报告怎么用

深度行业报告价值高于个股晨会。用法：

1. 抄它的产业链地图和产能表，不抄结论。
2. 把份额、价格、利润率做成自己的简表。
3. 每年只更新变化的部分。
4. 用本仓库行业分跟踪：增长、集中度、政策、估值分位是否漂移。

## 建立自己的研报档案

对每篇准备引用的报告记录：

- 日期、机构、标的、评级、目标价
- 关键假设（可证伪）
- 隐含倍数
- 利益冲突
- 三个月后回顾：假设对了没有

回顾比收藏 PDF 更重要。
